# 조선 무인 영웅전: 좀비 디펜스 (Joseon Heroes: Zombie Defense)

1인칭 슈팅 아케이드 게임 개발 프로젝트 - Kotlin & Android

## 📋 프로젝트 개요
한국의 역사적 영웅들이 좀비 떼로부터 조선을 지키는 무한 스테이지 슈팅 아케이드 게임입니다.
플레이어는 이순신, 이성계 등 역사적 인물을 선택하여, 사방에서 몰려오는 좀비들을 처치하고 스테이지를 돌파하며 성장합니다.

## 🎮 게임 기획 및 설계

### 1. 게임 컨셉 (Game Concept)
- **장르:** 1인칭 슈팅 / 아케이드 디펜스
- **시점:** 1인칭 시점 (FPS) 또는 아케이드 탑다운 (구현 단계에서 최적화)
- **목표:** 끝없이 이어지는 스테이지에서 최대한 오래 생존하고 높은 점수를 획득.

### 2. 조작 방식 (Controls)
사용자의 요청에 맞춘 커스텀 UI 레이아웃:
- **우측 하단 (Right Bottom):** 방향키 (이동/시선 처리)
- **좌측 하단 (Left Bottom):**
    - 공격 버튼 (기본 공격)
    - 무기 변경 버튼
    - 필살기 버튼

### 3. 캐릭터 및 무기 시스템 (Characters & Weapons)
총 8명의 역사적 영웅 선택 가능. 각 캐릭터는 고유한 무기와 특성(공격력, 방어력, 이동속도)을 가짐.

| 캐릭터 | 주무기 | 타입 | 특성 (ATK / DEF / SPD) | 필살기 |
|---|---|---|---|---|
| **이순신** | 쌍룡검 | 근접 | 중 / 상 / 중 | 거북선 포격 지원 (광역 폭발) |
| **이성계** | 각궁 | 원거리 | 상 / 하 / 상 | 편전 연사 (고속 연사) |
| **척사광** | 곡산검 | 근접 | 최상 / 하 / 최상 | 검무 (주변 적 즉사급 데미지) |
| **왕건** | 삼한창 | 근접(중거리) | 중 / 중 / 중 | 후삼국 통일 (아군 소환/버프) |
| **궁예** | 미륵의 눈 | 마법 | 최상 / 최하 / 하 | 관심법 (화면 전체 데미지/스턴) |
| **단군** | 천부인 | 마법/버프 | 중 / 중 / 중 | 홍익인간 (체력 회복 및 무적) |
| **광개토대왕**| 대검 | 근접 | 상 / 상 / 하 | 대륙의 기상 (돌진 공격) |
| **장수왕** | 철퇴 | 근접 | 상 / 최상 / 최하 | 철벽 방어 (일시적 무적 및 반사) |

- **무기 성장:** 스테이지 클리어 시 무기 공격력, 이펙트 강화 (화려해짐).
- **공격 타입:** 근접(검/창), 원거리(활), 마법(법술).

### 4. 좀비 및 스테이지 시스템 (Enemies & Stages)
- **무한 스테이지:** 스테이지가 거듭될수록 난이도 상승.
- **좀비 종류:**
    - 일반 좀비
    - 러너 (빠름, 체력 낮음)
    - 탱커 (느림, 체력 높음)
    - 보스 (특수 패턴)
- **점수 시스템:**
    - 처치 점수: 좀비 종류별 상이.
    - 시간 보너스: 스테이지를 빨리 클리어할수록 높은 경험치/점수 획득 -> 더 좋은 무기 업그레이드 가능.

## 🏗️ 개발 로드맵 (Development Plan)

### Phase 1: 프로젝트 설정 및 아키텍처 설계
- [ ] Android Kotlin 프로젝트 구조 재정비
- [ ] Game Engine 아키텍처 설계 (GameLoop, EntitySystem)
- [ ] UI 레이아웃 구조 잡기 (우측 방향키, 좌측 액션 버튼)

### Phase 2: 코어 게임 로직 구현
- [ ] **Player Class:** 영웅 스탯, 무기 시스템 구현 (Strategy Pattern)
- [ ] **Enemy Class:** 좀비 AI (플레이어 추적), 종류별 스탯 구현 (Factory Pattern)
- [ ] **Combat System:** 공격 판정, 데미지 공식, 쿨타임 처리

### Phase 3: 스테이지 및 성장 시스템
- [ ] **Wave Manager:** 스테이지별 좀비 생성 로직, 난이도 조절
- [ ] **Upgrade System:** 경험치 획득, 레벨업, 스탯 강화 로직
- [ ] **Score Manager:** 시간 비례 점수 계산 알고리즘

### Phase 4: UI 및 리소스 연동
- [ ] 인게임 HUD 구현 (조작키, 체력바, 점수)
- [ ] 캐릭터 선택 화면 구현
- [ ] 게임 오버 / 결과 화면

### Phase 5: 최적화 및 테스트
- [ ] 메모리 최적화 (Object Pooling 적용)
- [ ] 밸런스 테스트
- [ ] 최종 코드 리팩토링 및 제출

## 🛠️ 기술 스택 (Tech Stack)
- **Language:** Kotlin 100%
- **Architecture:** MVVM + Game Loop Pattern
- **Rendering:** Android Canvas API (Custom View) for Arcade feel
- **Design Patterns:** Singleton (Manager), Factory (Enemy/Weapon), Strategy (Attack Behavior), Observer (Game Events)
